### 教务系统导入

![学校登录页、课表页一键导入、选学期、预览](docs/screenshots/group9.png)

「我的 → 账号 → 教务账号」管理学校登录。教务账号卡片显示学校、学期和上次同步结果；点按卡片更新课表，左滑退出登录，开关只控制后台自动更新。教务自动更新在应用回到前台时检查，每 24 小时最多执行一次。先用该学校会话 Cookie 读取课表；会话失效时，若用户开启了“保存密码”，使用 Android Keystore 保护的本机凭据重新登录并重试一次。初次开启保存密码不会提交登录；用户可查看输入的密码，点击登录成功后才保存凭据，此后再次进入登录页可自动登录。退出登录或清除全部数据时删除会话与凭据。凭据密文不参与系统备份。

新疆理工职业大学使用正方移动端课表接口：先读取学期周次表，再逐周请求实际课表；逐周数据作为最终排课来源，按课程、教师、地点、星期和节次合并，保留每周差异。整学期结果仅作为接口对照，不用于覆盖周课表。周次请求结果在当前页面会话中缓存，切换学期或页面后重新获取；任一周读取失败不应用不完整课表。

## 功能

**今天**

- 日期时间线从设定的开学周算第 1 周；无课日按周折叠成日期区间，跨周不合并；连续假期显示名称、日期和天数，有课或调休的日期单独呈现
- 底部日期条随时间线定位，折叠区间内仍可选择具体日期；月历面板从底部打开
- 上课、下课倒计时按系统整分钟自动刷新，所有页面共享一个时钟；后台暂停计时，回到前台立即校时，最后一个订阅页面卸载后释放计时与监听；上课状态与日期同步切换
- 假期卡片旁的「调休安排」及「我的 → 设置 → 学期 → 调休安排」进入同一页面；补课日期是实际要上课的日子，课表日期是要补哪天的课

**课表**

- 周视图网格，正在上的课高亮，单双周、假期、考试周均有标注
- 时间重叠自动检测，支持「都保留」或「只留一门」决策，被隐藏的课可随时恢复
- 长按课程卡片可静音本节、标记已上、请假一次、查看变更记录、编辑课程或停课

**课程**

- 详情页展示下次上课时间、地点、老师、上课日、考核方式、提醒、学期进度、出勤、作业与备忘
- 编辑时可选生效范围「仅本次」或「每周」，可调整状态、时间、地点、老师、备注、颜色
- 单节 Override 与常规规则分离，每次修改留一条变更记录，支持撤销

**导入**

- 内置规则支持 JSON、Excel（xlsx）、教务系统 HTML 网格、ICS 日历、CSV
- **让 AI 转换课表**：一键复制经过设计的 Prompt，把课表文字或截图交给任意 AI，粘贴 JSON 即可导入，兼容 ```json 代码块
- 解析后进入预览，新增、变化、无法解析逐条列出，确认后完成导入；重复导入做三方合并，手动改过的字段不被覆盖
- JSON 带 `timeSlots` 时自动更新学期节次表；课程节次超出时自动补足

**待办**

- 作业、考试、自定义待办，可挂在课程上，按今天、近期、已完成分组

**提醒与小组件**

- 「我的 → 设置 → 提醒」统一管理提醒方式与时机，不再提供重复的上课/作业入口。支持关闭、系统日历、应用通知；切换时先清理旧通道，避免重复提醒。旧版已开启日历的选择会保留。
- 系统日历方式将课程、作业、考试和周次同步至应用自己的日历；应用通知方式把真实课程和待办投影为本机持久计划，由原生闹钟触发，重启或修改系统时间后重排。关闭或清除数据时取消本地计划与通知。日历清理权限被撤销时，不会直接启用新通道。
- 作业提醒来自有截止日期、未完成的待办，不从教务导入虚构作业。应用通知的课程卡片区分课前/课中，展示课程名、地点、起止时间和教师信息；「下课倒计时」控制上课后是否显示剩余时间，关闭后显示上课状态。倒计时交由系统时钟绘制，不按秒唤醒应用。
- 「刷新状态」只读通知权限与系统能力，不清空当前提醒方式、不重建提醒计划；固定反馈行显示检查中、已刷新时间或失败原因，不挤动下方设置。
- 停课、请假的那节保留在日历里（标题带「停课」「请假」，不提醒）；老师电话写在事件描述里可直接拨号
- 学期结束后课程日历自动从日历列表隐起，记录保留；在系统日历里手动改的颜色不会被同步覆回
- 4 款桌面小组件：今日、下一节、两日、本周，跟随系统深浅色；应用内预览的倒计时与日期实时刷新

**Android**

- 日期、时间、下拉选择支持系统原生对话框
- Android 13+ 主题图标（monochrome）、自适应开屏、边到边加安全区
- 系统返回键依次关闭菜单或面板、出栈、回到「今天」、两次返回退出

**超级岛调试**

- 「我的 → 关于」的应用图标 900ms 内连点三次，进入「调试 → 超级岛测试」。
- 仅手动发送固定测试通知，不读取课表，不启用自动提醒或后台调度，通知两分钟后超时。应用本身也是 LSPosed 模块：在管理器启用 Koma 并勾选 SystemUI，重启 SystemUI 或设备后生效；不需要给应用授予 Root。仅处理 `moe.tnxg.timetable` 的焦点鉴权，不放行其他应用。
- 模块握手成功时使用小米焦点模板，否则使用 Live Updates。已在 HyperOS 4 / Android 17 实机观察到模块 Hook 就绪、`onAuthSuccess`、`focusType=PARAMS` 与原生岛数据注册；其他系统版本仍需验证。
- 应用启动时注册正式「课程实时通知」渠道（`course_live_v1`），默认无声、无振动、不显示角标；同时移除旧调试渠道。注册渠道不会发送通知，系统中已有的渠道开关选择保持有效。
- 「检查」分别显示通知总开关、渠道、提升权限声明、系统提升开关、活动通知提升特征及系统实际提升标记。「提升通知设置」进入系统授权页，返回应用时刷新状态，不自动发送；发送后回桌面观察，再检查系统标记。提交成功或系统提升都不等于超级岛实际展示。浏览器禁用所有原生测试操作。
- Debug 进入时自动检查一次，回前台刷新；默认显示路径、权限与测试操作，Hook 明细折叠，可复制诊断 JSON。

## 快速开始

```bash
# Node 22
npm ci
npm run dev            # http://localhost:5173，浏览器直接调试 Web 端
```

界面通用图标使用 `~icons/mingcute/*`；空状态插画、加载动画及课程贴纸保留定制 SVG。生产界面与 `src/App.tsx` 原型逐屏核对尺寸、颜色和状态。

完整验证：

```bash
npm run check          # tsc --noEmit && vitest run && vite build
```

Android debug 包：

```bash
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64   # JDK 21
npm run build && npx cap sync android
cd android && ./gradlew assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk
```

Gradle 下载慢时在 `~/.gradle/init.gradle` 加国内镜像；见 [AGENTS.md](AGENTS.md#部署与打包)。
